\cvsection{Research Experience and Projects}
\entry{OmniToM: LLM Social Reasoning Evaluation Benchmark}{Oct 2025 -- Present}{Research project, University of Central Florida}
\begin{itemize}
  \item Co-developed a benchmark from 895 stories with 22,343 structured belief propositions and 156,401 labels, using a human-validated annotation pipeline developed with 11 annotators and about 1.1K person-hours of annotation work.
  \item Coordinated annotation quality control and validation, and designed structured prompts for belief extraction and seven-dimension belief labeling.
  \item Evaluated API and open-weight models across Azure OpenAI, Anthropic, Google Vertex AI, and university and NSF ACCESS HPC resources; built parallel and batch evaluation workflows for model comparison.
\end{itemize}

\entry{BIAS-101: Demographic Bias in Video Action Recognition}{Jan 2025 -- Apr 2025}{Research project, University of Central Florida}
\begin{itemize}
  \item Built a video collection and filtering pipeline using platform APIs, automated quality checks, vision-language models, and multimodal annotation to audit demographic representation in UCF-101.
  \item Processed more than 85,000 candidate videos and added more than 2,000 curated clips for dataset rebalancing; assessed demographic patterns with statistical tests and a dominance-ratio measure.
\end{itemize}

\entry{DETECT: Deception Tracking Through Eye Cues Technology}{Aug 2024 -- Apr 2025}{Faculty-advised, 6-member team project}
\begin{itemize}
  \item Led development of a real-time gaze and facial-signal tracking system using MediaPipe FaceMesh, with reported gaze-tracking accuracy above 80\% in the project evaluation.
  \item Built and deployed the full-stack application using Astro, Go, PostgreSQL, Docker, and DigitalOcean.
\end{itemize}

\entry{CLEAR: Video Denoising Evaluation}{}{Research project, University of Central Florida}
Compared traditional and AI-based denoisers on more than 13,000 videos, using Python and OpenCV to generate noise conditions and PSNR, SSIM, and VIF to evaluate output quality.
